## ✨ Features

- 🎉 Interactive welcome screen
- 🎂 Animated birthday cake with candles
- 🎆 Confetti animation effects
- 💖 Heartfelt birthday message
- 📱 Fully responsive design
- ✨ Smooth animations and transitions

## 🚀 How to Use

1. Simply visit the link above
2. Click anywhere on the welcome screen to reveal the surprise
3. Click "Click here for another surprise 💝" to see the cake
4. Click "Blow out the candles 🕯️" for the finale!

Enjoy! 🎊
